## Cyber Suite: a modular robotics research platform

Cyber Suite is our actively developed software platform connecting robot modeling, motion planning, whole-body control, simulation, and learning through a C++ core and Python interfaces. It brings reusable components together with structured logging, visualization, and experiment analysis.

**[Explore Cyber Suite](/cyber-suite/)** for its research focus, software overview, and public release announcements.

## FROST: trajectory optimization and simulation

FROST is an open-source MATLAB toolkit for modeling hybrid dynamical systems, generating constrained robot motions, and simulating locomotion. Its symbolic modeling and direct collocation tools support research on dynamic walking.

- [Source code and installation instructions](https://github.com/ayonga/frost-dev)
- [Documentation](https://ayonga.github.io/frost-dev/)
- [Example models and optimization problems](https://github.com/ayonga/frost-dev/tree/master/example)
- [Paper and downloadable citation](/publication/hereid-2017-frost/)
- [Project overview](/project/frost/)

Check the repository's installation requirements before running an example. Use the paper to cite the method and the repository to identify the software version used in an experiment.
